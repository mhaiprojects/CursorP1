# POE1

Minimal Path of Exile 1 reference project: cloned open-source tools, documentation, and budget build guides.

## Structure

```
docs/           Documentation
repos/          Cloned POE tools (Path of Building, poe.ninja clients)
POE1Builds/     Budget build recommendations
```
